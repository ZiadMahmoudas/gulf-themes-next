# ArabDEV V23

## Rich Editor
- Rebuilt the article toolbar so `P / H1 / H2 / H3 / H4 / H5 / H6` are visible inside one clear "نوع النص" select.
- Added a prominent `+ رفع صورة` button.
- Image insertion uses the current cursor position and uploads to the `media` Supabase bucket.
- Added Arabic labels explaining exactly what P and H1-H6 mean.
- Added V23 marker so it is obvious which editor version is actually running.
- Added distinct typography for paragraph and every heading level in the editor.

## Home
- Rebuilt Home again with isolated V23 class names instead of stacking fixes over old V14/V20 styles.
- Hero no longer mixes Arabic and `WordPress` inside one visual line; each headline line is a separate block.
- Featured product image comes from Dashboard first, Unsplash only as fallback.
- Added 3 clear service choices, product grid, editorial story block, 3-column article grid, FAQ and CTA.
- Responsive typography and mobile layouts have their own V23 rules.
