# ArabDEV V25

- Converted the single article experience from full dark mode to the same warm/light visual language used across ArabDEV.
- Kept the article layout editorial, with a soft latest-articles card, readable body column, light reading note, polished images, H1-H6 support, lists and captions.
- Redesigned Theme, Plugin and Article library cards so all titles/descriptions/meta sit under the artwork instead of on top of it.
- Product artwork is now completely clean; no overlay title, category, badge or CTA is rendered over images.
- Added subtle hover lift, paper cards, lightweight status chips and cleaner detail actions.
- Plugins now use a balanced 2-column desktop layout and all library cards collapse cleanly to one column on mobile.
- No dependencies added and no data model changes required.
